# สมุดบันทึกแฟนเชลซีของโอห์ม — ข้อเสนอ Dashboard

โอมเลือกให้บันทึกความทรงจำและความเห็นหลังเกมเป็นส่วนหลัก ยังไม่ได้เปลี่ยน Dashboard ให้บันทึกข้อมูลจริงในรอบนี้

1. บันทึกหลังเกม: คู่แข่ง วันที่ สกอร์ ความรู้สึกหลังดูเกม และความเห็นของโอห์ม แยกข้อความที่เขียนเองจากข้อมูล API
2. นักเตะยอดเยี่ยมของผม: เลือกหนึ่งคนพร้อมเหตุผล เป็นความเห็นของโอห์ม ไม่ใช่รางวัลทางการ
3. โมเมนต์ที่อยากจำ: รูปที่โอมถ่ายหรือเลือก พร้อมคำบรรยายและวันที่
4. เส้นเวลาแฟนเชลซี: เรียงบันทึกล่าสุด กรองตามฤดูกาลหรือความรู้สึก

แนะนำให้เริ่มที่บันทึกหลังเกมก่อน รองรับร่างส่วนตัวและเผยแพร่เมื่อเจ้าของกดเอง การเขียนบนเว็บต้องยืนยันบัญชีเจ้าของก่อน ไม่เปิดให้ผู้เข้าชมแก้ไขบันทึกได้ และไม่แสดงบันทึกตัวอย่างเป็นเรื่องจริงของโอห์ม
