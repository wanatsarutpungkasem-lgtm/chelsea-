URL เดิม: https://wanatsarutpungkasem-lgtm.github.io/chelsea-/dashboard.html

ฐานข้อมูลและ RLS ถูกติดตั้งในโปรเจกต์ Supabase เดิมแล้ว ไม่ต้องรัน SQL ซ้ำ ไม่ต้องตั้ง Netlify และไม่ต้องวาง API-Football key หรือ service-role key ใน GitHub

## บัญชีเจ้าของ

บัญชีเว็บไซต์แยกจากบัญชี Supabase Dashboard และ GitHub:
1. กด “สร้างบัญชีเว็บครั้งแรก” กรอกอีเมลเจ้าของที่อนุมัติไว้ ตั้งรหัสผ่านอย่างน้อย 8 ตัวอักษร และใส่ยืนยันให้ตรงกัน
2. กด “สร้างบัญชีและส่งอีเมลยืนยัน” เปิดอีเมลและกดลิงก์ยืนยัน
3. กลับมาหน้า Dashboard เข้าสู่ระบบด้วยรหัสผ่านที่เพิ่งตั้ง
4. ระบบตรวจอีเมลที่ยืนยันแล้วและขอสิทธิ์เจ้าของกับฐานข้อมูล บัญชีอื่นเขียนหรืออ่านร่างไม่ได้

Site URL ตั้งเป็น Dashboard บน GitHub Pages และเพิ่ม Redirect URL `http://127.0.0.1:4173/dashboard.html` สำหรับทดสอบแล้ว

## ร่างและโพสต์สาธารณะ

- กดบันทึก: เก็บร่างใน `journal_entries` อ่านและแก้ได้เฉพาะเจ้าของ
- กดเผยแพร่บนการ์ด: ฐานข้อมูลคัดลอกฉบับที่บันทึกแล้วไป `journal_publications` ผู้เยี่ยมชมจึงอ่านได้
- แก้ร่างหลังเผยแพร่: ฉบับสาธารณะเดิมยังอยู่จนกดเผยแพร่ฉบับแก้ไข
- นำออกจากหน้าสาธารณะ: เก็บร่างเดิมไว้
- บันทึกเดิมในเครื่องไม่ถูกส่งขึ้นอัตโนมัติ กด “นำบันทึกในเครื่องขึ้นคลาวด์เป็นร่าง” เมื่อพร้อม ระบบข้ามรหัสเดิม ไม่เขียนทับ และไม่เผยแพร่
- ส่งออก JSON ก่อนย้ายเครื่องหรือล้างข้อมูลเบราว์เซอร์ ไฟล์สำรองอาจมีฉบับร่างส่วนตัว
- ระบบตรวจ version เพื่อป้องกันการเขียนทับเมื่อแก้พร้อมกันหลายแท็บ
